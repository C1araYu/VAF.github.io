How do Visual Attributes Influence Web Agents?
A Comprehensive Evaluation of User Interface Design Factors

Anonymous ACL submission
Project: VAF
ACL 2026 Submission
Paper Supplementary Code (coming soon) arXiv

VAF studies how visual changes to a target item on real-world webpages affect web-agent behavior through content-preserving variant generation, human-like browsing interaction, and validation with both click actions and reasoning traces.

Abstract

Web agents have demonstrated strong performance on a wide range of web-based tasks. However, existing research on the effect of environmental variation has mostly focused on robustness to adversarial attacks, with less attention to agents' preferences in benign scenarios. To address this, we introduce VAF, a controlled evaluation pipeline for quantifying how webpage visual attribute factors influence web-agent decision-making. VAF consists of three stages: (i) variant generation, which ensures the variants share identical semantics as the original item while differing only in visual attributes; (ii) browsing interaction, where agents navigate the page via scrolling and clicking the interested item, mirroring how human users browse online; and (iii) validation through both click action and reasoning traces, which we use to compute Target Click Rate and Target Mention Rate. Across 8 variant families, 48 variants, 5 real-world websites, and 4 representative web agents, we find that background color contrast, item size, position, and card clarity strongly influence agent decisions, whereas font styling, text color, and image clarity exhibit relatively minor effects.

Highlights

  • Controlled visual variants: VAF modifies only CSS-based visual attributes of a designated target item while preserving webpage semantics and functionality.
  • Human-like browsing: Agents observe sequential viewports and interact through scrolling and clicking rather than making decisions from a single screenshot.
  • Dual validation: VAF measures both Target Click Rate and Target Mention Rate to quantify how visual attributes influence actions and reasoning.
  • Main finding: Background color contrast, card size, position, and card clarity are the strongest drivers of agent behavior across websites and models.

Variant Families

Background color variants produce some of the largest shifts in target click behavior.

Position and order changes strongly affect whether the target item is noticed or ignored.

Larger cards and clearer target regions substantially improve attraction for multiple agents.

Font family and text color changes generally have smaller effects than layout and saliency cues.

Method Overview

Starting from HTML snapshots of real-world webpages, VAF selects a target item and generates visual variants by changing only CSS attributes such as background color, text color, font family, font size, position, card size, clarity, and order. During evaluation, an agent observes a 1280×1200 viewport, scrolls up or down to explore the page, and finally clicks the item it considers most attractive. VAF then measures the impact of each variant by comparing the agent's target click behavior and whether the agent explicitly mentions the target item in its reasoning.

Key Findings

High-Impact Attributes

Background color contrast, enlarged card size, and earlier on-page position consistently increase target attraction across diverse models and websites.

Position Bias

Agents are much more likely to click items that appear near the top of the page, reflecting a strong positional prior similar to human browsing patterns.

Card vs. Image Clarity

Blurring the full card harms performance much more than blurring only the image, suggesting that current web agents remain strongly text-centric.

Agent-Human Similarity and Gap

Agents share surface-level attentional biases with humans, but they are more brittle once visual grounding breaks or the target becomes less salient.
